# 自动后期 v2 操作手册（普通操作者）

适用：`video_postprod` 编辑任务合同 `edit-job/v2`（2026-10-11 编排升级后）。日常操作全部在网页 UI 完成，不需要填写 JSON、绝对路径或开发 Agent。

## 账号

剪辑引擎不绑定任何账号。每个账号的声音、默认配乐、可导入目录和附加写稿/核查/审片规则，写在该账号自己项目里的账号配置文件中，并登记在 `config/account_profiles.json`。网页顶部选账号和栏目即可；接入新项目的步骤见 `.agents/skills/auto-postprod/SKILL.md`。

- 新任务提交时会锁定当时的账号配置；之后的修订一直沿用这一版，配置文件再改也不影响已有任务。要用新配置，新建任务。
- 账号锁定上线前创建的旧任务没有锁定记录，继续按原来的方式重放。
- 当前已登记：老X（`F:/codex/laox_account/config/postprod_profile.json`）。

## 启动

双击项目根目录 `自动剪辑.cmd`（或 `scripts/start.ps1 -OpenUI`）。浏览器打开 `http://127.0.0.1:8760/#<令牌>` 即完成登录。四个本地组件（调度、MPT、Narrato、Cosy）由 supervisor 自动拉起。

## 一条视频的标准流程

1. **导入素材**（可多选、顺序无关）
   - 每个视频选择角色：
     - `商品画面 · 自由剪辑`：进入候选镜头库，由系统按句选镜；
     - `固定开头/固定中段/固定结尾 · 保留原声`：数字人口播片段，原音画锁定、不裁切、不参与自由选镜；需填写口播台词用于核对。
   - 分析方式：`按整段分析`（默认）或 `按场景检测切镜`（调用本机 PySceneDetect 产生候选窗口）。
   - 无关素材可以一起导入：系统会按画面内容与整稿的相关性排除，不会用无关画面填空。
2. **配音方式（三选一，不会自动切换）**
   - `自动配音`：用所选账号配置里的声音与默认 preset 对整稿连续合成一次；
   - `上传现成配音`：选择 WAV/MP3；任务内 TTS 调用为 0；
   - `使用已确认的历史配音`：只列出曾试听确认且文件校验通过的版本。
3. **整稿**：粘贴完整口播稿（或选择生成整稿，需付费额度）。分句决定镜头段落；整稿顺序就是叙事顺序。
4. **提交**：勾选必要的授权（色彩预览、付费额度）后点“自动剪辑”。

## 阶段确认（每步都要人确认，不确认不往下走）

| 界面状态 | 含义 | 操作 |
|---|---|---|
| 待确认整稿 | 整稿已解析成句 | 核对后点“确认这版整稿” |
| 待试听配音 | 配音音频就绪 | 试听后点“确认这版配音”；不满意就停止并新建版本 |
| 待字幕校对 | 实际声音 vs 原稿逐句比对 | 每句可播放对应音频区间；`声音正确，修正识别`（按原稿改字幕）、`声音读错，需重配`（停止，改稿或换音频）、`接受漏读/接受多读`。未确认的句子不会自动过关 |
| 缺镜头素材 | 某句的镜头需求无可用候选 | 界面列出句号与需求；补充素材后新建版本，不要用无关画面补 |
| 需重配声音 | 有句子确认是声音读错 | 修改该句文字后新建版本，或上传修正音频 |
| 待审阅 | 成片已生成 | 预览、逐项审阅（画面/色彩/声音/字幕/事实/嘴型/切点） |

## 修订（都生成新版本，旧版本不可变）

- **改字幕文字**：在“字幕修订”里直接改文本，保存新版本。只重新烧录字幕，配音、分析、选镜全部复用。
- **只换一个镜头**：在镜头列表点“查看备选并替换这一镜”，选择候选、填写理由。同长度换镜，不重配音；与其他镜头源窗重叠的候选需明确允许并留痕。
- **配乐**：改音量或替换文件（需填写来源与授权说明）。默认配乐来自账号配置（老X为 Montauk Point），只在发布文案署名，不进画面。
- **付费额度**：每任务默认上限 2 元/40 次请求；额度不足时相关阶段会明确阻塞，不会绕过。

## 模型分工（新建 v2 任务，`providers.text = ark-text-agent`）

| 环节 | 模型 | 路径 |
|---|---|---|
| 整稿生成 | doubao-seed-2-1-turbo（剧本创作 Agent） | 火山方舟，计入 2 元额度 |
| 事实核对（仅当账号配置写了核查规则） | doubao-seed-2-1-lite | 火山方舟，只记录，不中断剪辑 |
| 选镜 | Clef-Flash 先排序，doubao-seed-2-1-lite 再做文字审片 | 本地 Clef 控制器 + 火山方舟 |
| 画面描述 | doubao-seed-2-0-lite | 火山方舟，计入上面的 2 元额度 |
| 配音 / 字幕识别 | Cosy / whisper-small | 本地按需加载 |

- 文本链路（整稿生成 + 事实核查 + Clef 文字审片）已整体切换到火山方舟 `ark-text-agent` 分档路由：整稿用 turbo 档（深度思考开启），审片用 lite 档（思考关闭，短 JSON 输出）。分档配置与价格上界见 `config/ark-text-agent.json`；两个档位的模型可用性由 `scripts/qualify-ark-text-agent.py` 实测，记录在 `state/deployment/ark-text-agent.json`。
- 文本调用与画面描述一起计入每任务默认 2 元/40 次额度；结果由网关 ledger 按请求回放，闸门后重跑不重复计费。
- Claude 调用不再参与新任务；旧任务和从旧任务派生的修订版仍按创建时的路线（`claude-cli` 或 `ark-approved`）回放，不会被改动。

## 边界与提醒

- 自动配音只接受账号配置里登记的声音与 preset；老X 的 selling 专属声线尚未配置，不虚构。
- 固定开头/结尾/中段保持完整原声与嘴型绑定，系统不会裁剪或覆盖。
- 模型给出的画面描述、字幕置信度都只是审阅参考；最终以人工看片、听审为准。
- 付费结果未知（SUBMISSION_UNKNOWN）时保留预算与回执，由操作者用回执信息核销，不自动重发。
- 旧 `edit-job/v1` 任务与既有成果不受影响，可继续读取/回放/修订。

## 常见问题

- **提示“缺镜头素材”**：按页面列出的句子和需求补拍/补素材，新建版本重跑；分析结果会按素材 hash 复用，不会重看不变化的素材。
- **字幕和听到的声音不一致**：以听到的为准——声音读对就“修正识别”，声音读错就“需重配”，不要用字幕掩盖读错。
- **想重跑但不想重配音**：只要整稿与配音方式不变，字幕/配乐/换镜修订都不会重新合成配音；改动整稿文字才会。
